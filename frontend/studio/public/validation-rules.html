OpenWorkflow Studio · deterministic local validation

Validation rule reference

Rules describe source shape and workspace relationships without evaluating user expressions or executing workflow side effects. Errors are not suppressible; warnings and informational compatibility findings may be suppressed by an approved project policy once suppression support is enabled.

studio.workflow.duplicate-id error · semantic

Workflow IDs must be unique across the workspace.

studio.workflow.duplicate-state error · semantic

State names must be unique within a workflow.

studio.workflow.start-reference error · semantic

The declared start state must exist.

studio.workflow.transition-reference error · semantic

Every transition target must name a declared state.

studio.workflow.dead-end error · semantic

A non-terminal state must have a normal or explicitly supported outcome.

studio.workflow.self-loop error · semantic

Accidental direct self-loops are rejected; use an intentional bounded loop construct when required.

studio.workflow.unreachable-state warning · semantic

The state is not reachable from the declared start path.

studio.workflow.switch-default warning · semantic

Switch states should define an explicit default outcome for unmatched input.

studio.workflow.unreachable-branch warning · semantic

An unconditional branch makes later switch branches unreachable.

studio.workflow.callback-event-correlation error · semantic

Callback states need an event reference for runtime correlation.

studio.workflow.unresolved-function error · semantic

A functionRef points at a function not declared in the workflow.

studio.workflow.catalog-alias error · semantic

A function operation uses an undeclared catalog alias.

studio.workflow.operation-unresolved error · semantic

The referenced operationId is absent from the resolved local catalog.

studio.workflow.subflow-unresolved error · semantic

A subflow reference does not resolve to a local workflow ID or path.

studio.workflow.unknown-extension warning · compatibility

The extension is preserved but is not interpreted by the local validator.

studio.workflow.expression-shape error · schema

Expression-bearing fields must remain authored, non-empty text.

studio.openapi.unresolved-ref error · semantic

A local OpenAPI JSON pointer cannot be resolved.

studio.openapi.external-ref warning · semantic

External references are reported as unresolved-by-policy and are never fetched by Studio.
